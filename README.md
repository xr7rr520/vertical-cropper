# 垂直藝術裁切器（網頁版）

純前端單頁工具，手機與電腦都能直接用。圖片完全在瀏覽器處理，不會上傳到任何伺服器。

## 使用

1. 用瀏覽器開啟 `index.html`
2. 選擇一張或多張圖片
3. 選比例（9:16、9:19.5 等）與裁切模式
4. 按「開始裁切」→ 預覽後點「下載」

也可把整個資料夾放到任何靜態網頁空間（GitHub Pages、Netlify、自己的主機），即可變成線上版。

## 功能

- 支援多張圖片一次處理
- 比例：9:16、9:19.5、2:3、3:4、1:1、自訂
- 裁切：智慧（細節最多）/ 置中 / 靠上 / 靠下
- 可選風格強化（提高對比與飽和）
- 輸出 JPEG，檔名自動加 `_crop`
